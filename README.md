# Accesibilidad en comunicaciones

Skill en español para redactar y revisar correos, formularios, agendas, artes, presentaciones y videos. Incluye un checklist operativo para eventos tecnológicos presenciales, virtuales e híbridos, con foco en personas Sordas e hipoacúsicas.

## Cómo usarlo

- **En un agente compatible con Agent Skills:** copia la carpeta [`accesibilidad-comunicaciones/`](accesibilidad-comunicaciones/) completa, con su `SKILL.md`, al directorio de skills de tu agente. El directorio y la forma de activación dependen de cada herramienta. En Codex, puedes elegir el skill por nombre cuando le pidas revisar una comunicación.
- **En otros asistentes o modelos:** pega el contenido de [`SKILL.md`](accesibilidad-comunicaciones/SKILL.md) como instrucciones para la tarea y adjunta el texto o material que quieres revisar. Esto no instala el skill ni habilita su activación automática.

Ejemplo: «Revisa este anuncio. Confirma qué información está solo en la imagen y no prometas interpretación ni subtítulos que aún no estén confirmados».

El skill solo contiene instrucciones en Markdown. No requiere dependencias ni credenciales, y no envía ni publica contenido.
